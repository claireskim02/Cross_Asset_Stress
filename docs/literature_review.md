# Literature Context And Benchmark Map

This is a working literature note, not a complete review. Its purpose is to map prior work to benchmark requirements so ChronoSwan does not mistake an engineering demo for a novel empirical contribution.

## 1. Options-Implied Tail Risk

The options literature already motivates volatility, skew, downside tail probability, variance risk premium, and OTM put-demand features. Cboe describes SKEW as an index estimating skewness of 30-day S&P 500 returns from option prices. Kelly and Jiang connect tail-risk measures to asset prices, option-implied skewness/kurtosis, and real economic activity.

Implication for ChronoSwan:

The structured benchmark must include derivatives-implied risk variables. A text or LLM agent must improve on these, not merely restate that markets are stressed when VIX is high.

Initial benchmark features:

- VIX level and change;
- VIX term structure or curve slope;
- implied volatility skew;
- risk reversal or OTM put demand;
- implied versus realized volatility spread;
- variance risk premium;
- option-implied tail probability when data exists.

Sources:

- Cboe SKEW: https://www.cboe.com/us/indices/dashboard/skew/
- Kelly and Jiang, "Tail Risk and Asset Prices": https://www.nber.org/papers/w19375

## 2. Stress-Regime Forecasting

Crash or stress forecasting with logistic models, regime models, tree models, and boosted classifiers is not novel by itself. The relevant standard is calibrated probability forecasting under time-series validation, not raw accuracy or a trading backtest optimized after the fact.

Implication for ChronoSwan:

Benchmarks need to be serious before the agent is evaluated. The first implemented model should be interpretable and difficult to overfit. Regularized logistic regression and hazard models are better initial anchors than a high-capacity ensemble.

Required metrics:

- Brier score;
- log loss;
- average precision;
- ROC AUC as secondary;
- calibration slope and intercept;
- expected calibration error;
- lead time before event onset;
- false alarms per year;
- event-level detection rate.

## 3. LLM Financial Forecasting

LLMs are widely studied for financial sentiment, disclosure interpretation, return forecasting, portfolio construction, and agentic workflows. A simple "ask an LLM if a crash is coming" study is crowded and weak unless the information set is controlled.

Implication for ChronoSwan:

The agent must be evaluated as an incremental information processor. It should receive timestamp-valid context and return a probability, confidence, risk factors, counterarguments, evidence IDs, and abstention state.

## 4. LLM Look-Ahead Bias

Look-ahead bias is central. Glasserman and Lin show that GPT-based financial sentiment backtests can be contaminated by later outcomes. Recent work extends this concern through benchmark design, cutoff-specific models, inference-time mitigation, and broader finance-LLM bias taxonomies.

Implication for ChronoSwan:

The project should report controlled and contaminated experiments side by side. If the contaminated model looks much better, that is not failure; it is evidence that the leakage audit is informative.

Sources:

- Glasserman and Lin, "Assessing Look-Ahead Bias in Stock Return Predictions Generated By GPT Sentiment Analysis": https://arxiv.org/abs/2309.17322
- Look-Ahead-Bench: https://arxiv.org/abs/2601.13770
- DatedGPT: https://arxiv.org/abs/2603.11838
- FinCAD: https://arxiv.org/abs/2605.24564
- Finance-LLM bias position paper: https://arxiv.org/abs/2602.14233
