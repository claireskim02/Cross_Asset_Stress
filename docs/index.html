ChronoSwan Chartbook

Point-in-time attribution of large ES impulses.

This research page summarizes the intraday branch of ChronoSwan in chartbook form. The study conditions on large 60-minute ES1 moves, benchmarks simple cross-asset correlations, then tests whether PCA adds a useful factor-concentration view.

Raw Bloomberg/Finaeon files, parquet caches, and executed notebooks are kept local. The public page reports methodology, sanitized sample rows, and aggregate findings only.

Page 0

Literature Context And Contribution

What is already known

Extreme-dependence studies show correlations differ in tails. Contagion work warns crisis correlations can be volatility-biased. DCC and spillover models are formal dependence benchmarks, and PCA absorption ratios already measure systemic concentration.

What this project contributes

The new object is the point-in-time ES impulse workflow: define large hourly ES moves with a shifted rolling threshold, compare conditional correlations first, then use PCA only if it clarifies driver structure or concentration.

Page 7

Current Readout

Main finding

Large ES impulses appear more cross-asset and more factor-concentrated than ordinary intraday bars. The cleanest evidence is the rise in PC1 variance share and rolling absorption during large-move windows.

What is not proven yet

The 140-day Bloomberg desktop window is too short for formal crisis inference. Predictive screens are early diagnostics and should not be described as trading models.

Next steps

Extend intraday history, compare against DCC and spillover baselines, stabilize PCA with top-10/top-20/weighted definitions, and add timestamp-aware macro or news synthesis only after structured benchmarks are frozen.
